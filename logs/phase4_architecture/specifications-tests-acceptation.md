# Spécifications des tests d’acceptation

**Exécution :** à faire uniquement sur base de test isolée avec données synthétiques. Ne pas exécuter les tests d’écriture sur la base `etat_civil_final_review_20261105_1304`. Comptabilité/POS doivent y être configurés seulement dans l’environnement autorisé prévu.

## Preuves de validation finale exigées

- Rapport XML/JSON des tests unitaires et suite Odoo ciblée, identifiant DB et commit exact.
- Résultats HTTP/RPC pour tests négatifs, sans secret; IDs synthétiques.
- Captures Chromium des prévisualisations et vues de chaque rôle, navigateur/version et URL sans identifiants.
- Extraits de données comptables synthétiques montrant facture, paiement, rapprochement et résiduel; pas de données réelles.
- Résultat de concurrence et clé d’idempotence; preuve qu’aucun doublon n’existe.
- Les tests liés aux décisions non encore tranchées (is_matched, remboursement, règle gratuite) restent EN ATTENTE jusqu’à décision formelle.
